# URCLUB Project Order Form (urclub-form.vercel.app)

فرم تخصصی، هوشمند و چندمرحله‌ای ثبت و شخصی‌سازی سفارشات استودیو URCLUB.

## ویژگی‌ها
- 🌐 **طراحی وب‌سایت**: انتخاب نوع سایت (فروشگاهی، شرکتی، پورتفولیو، لندینگ، آموزشی)، پالت رنگ و تم بصری، نوع دامین (.com, .net, .org, .vercel.app)، دیتابیس (سوپابیس/اختصاصی)، امکانات و تعداد صفحات.
- 📱 **برنامه موبایل**: پلتفرم (Android/iOS)، موضوع، دیتابیس و سیستم احراز هویت.
- 💻 **نرم‌افزار کامپیوتر**: سیستم‌عامل (ویندوز، مک، لینوکس)، نوع برنامه و سیستم داده.
- 🎨 **طراحی پوستر و گرافیک**: ابعاد (استوری 1080x1920، پست، کاور یوتیوب، چاپ A3/A4)، عنوان اصلی، سبک طراحی و رنگ‌ها.
- ✉️ **ارسال خودکار به ایمیل**: ارسال مستقیم تمامی اطلاعات ساختاریافته به ایمیل `urclub7@gmail.com`.
- ☁️ **پشتیبان‌گیری ابری**: ذخیره نسخه پشتیبان در دیتابیس ابری Supabase تا هیچ تماسی از دست نرود.
- 💬 **اتصال به واتساپ و تلگرام**: تولید کد پیگیری اختصاصی و ارسال پیام سریع با یک کلیک.

## نحوه انتشار در Vercel:
1. در گیت‌هاب یک مخزن جدید به نام `urclub-form` بسازید:
   ```bash
   git init
   git add -A
   git commit -m "feat: initial release of urclub dynamic order form"
   git branch -M main
   git remote add origin https://github.com/urclub7-ai/urclub-form.git
   git push -u origin main
   ```
2. در پنل کاربری ورسل (Vercel Dashboard)، روی `Add New Project` کلیک کرده و مخزن `urclub-form` را ایمپورت کنید.
3. در تنظیمات پروژه، دامین آن به صورت پیش‌فرض یا انتخابی روی `urclub-form.vercel.app` تنظیم خواهد شد.
